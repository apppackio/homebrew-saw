# apppackio/homebrew-saw

Homebrew tap for [saw](https://github.com/apppackio/saw), a fast,
multipurpose tool for AWS CloudWatch Logs.

## Install

```sh
brew install --cask apppackio/saw/saw
```

## Note

`Casks/saw.rb` is generated by [GoReleaser](https://goreleaser.com) when a
release is tagged in [apppackio/saw](https://github.com/apppackio/saw).
Do not edit it by hand; changes will be overwritten by the next release.
